# Nenúfar product page visual treatment

## Objective

Bring the live Shopify product page into the Nenúfar visual language while retaining existing product, variant, personalization, cart, and checkout behavior.

## Scope

- Added Nenúfar styling for product imagery, title, price, options, personalization input, purchase action, and description.
- Replaced generic English purchase labels with Spanish.

## Validation

- `npm run typecheck`
- `npm run build`

Both completed successfully.

## Rollback

Revert this commit to restore the previous generic Hydrogen product-page styling and labels.
